# Plano de Execução — Set Eletrônico Nostálgico e Transcendental

## 1. Objetivo

Criar um set eletrônico com narrativa progressiva, emocional e cativante, combinando nostalgia e produção contemporânea para um público formado principalmente por pessoas nascidas nas décadas de 1980, 1990 e 2000.

A proposta não é criar um set exclusivamente retrô. O conceito central é:

> Produção moderna + melodias conhecidas + vocais nostálgicos + progressão consistente de energia.

O set deve conduzir o público por uma jornada:

```text
Mistério
   ↓
Descoberta
   ↓
Conexão
   ↓
Celebração
   ↓
Escuridão
   ↓
Libertação
   ↓
Retorno emocional
```

---

## 2. Formato das faixas

Todas as faixas serão fornecidas em formato `.mp3`.

### Requisitos recomendados

Priorizar arquivos com:

- bitrate de 320 kbps;
- sample rate de 44,1 kHz;
- estéreo;
- origem confiável;
- ausência de cortes no início ou no final;
- ausência de distorção, clipping ou volume excessivamente comprimido.

### Evitar

- arquivos de 128 kbps quando existir versão melhor;
- arquivos convertidos de YouTube;
- arquivos que já foram convertidos várias vezes;
- transformar um MP3 de baixa qualidade em MP3 de 320 kbps;
- normalizar ou recomprimir todos os arquivos antes da análise;
- alterar o arquivo original sem manter uma cópia.

Converter um MP3 de baixa qualidade para uma taxa maior não recupera informação perdida.

### Estrutura de backup

Manter duas pastas:

```text
/SET_MASTER
    /01_ORIGINAIS
    /02_PREPARADAS
```

Os arquivos da pasta `01_ORIGINAIS` não devem ser alterados.

## 3. Organização dos arquivos

### Estrutura sugerida

```text
/DJ_SET_NOSTALGIA
    /01_PORTAL
    /02_MELODIC_HOUSE
    /03_BRAZILIAN_GROOVE
    /04_NOSTALGIA
    /05_MELODIC_TECHNO
    /06_PEAK_CROSSOVER
    /07_TRANCE
    /08_FINAL
    /EDITS_E_MASHUPS
    /BACKUP
```

### Padrão de nome

```text
NN - Artista - Música - Versão.mp3
```

Exemplo:

```text
01 - Adriatique & Delhia de France - The Future Is Unknown.mp3
02 - Nosi - Weightless.mp3
03 - Teho - Space Explorers.mp3
```

Para edits e mashups:

```text
Artista - Música - Nome do Edit - EDIT.mp3
```

### Metadados mínimos

Preencher, quando possível:

- artista;
- título;
- versão;
- ano;
- gênero;
- comentário com a função no set;
- classificação por estrelas;
- cor ou tag de energia.

Exemplo de comentário:

```text
ATO 5 | ÂNCORA | MELODIC TECHNO | 126 BPM | EMOCIONAL
```

## 7. Curva aproximada de BPM

| Etapa | Faixa aproximada |
|---|---:|
| Introdução atmosférica | livre ou sem kick |
| Abertura progressiva | 112–120 BPM |
| Melodic House | 120–124 BPM |
| Brazilian Bass / Deep / Future House | 122–126 BPM |
| Progressive nostálgico | 124–128 BPM |
| Melodic Techno | 125–130 BPM |
| Peak Crossover | 128–134 BPM |
| Trance Melódico | 130–138 BPM |
| Final emocional | livre, conforme a faixa |

O BPM não deve ser a única referência. A percepção de energia depende também de:

- densidade do kick;
- intensidade dos graves;
- quantidade de elementos;
- presença vocal;
- duração dos breakdowns;
- tensão harmônica;
- familiaridade da música.

# 10. Preparação técnica dos MP3

## 10.1 Importação

Importar todos os arquivos no software escolhido:

- Rekordbox;
- Traktor;
- Serato DJ;
- VirtualDJ;
- Mixxx.

## 10.2 Análise automática

Executar análise de:

- BPM;
- tonalidade;
- waveform;
- ganho;
- beatgrid;
- duração;
- presença de silêncio inicial.

A análise automática deve ser revisada manualmente.

## 10.3 Beatgrid

Verificar especialmente:

- edits;
- mashups;
- músicas antigas;
- músicas com introduções livres;
- faixas com bateria humana;
- arquivos com BPM variável;
- versões obtidas fora de lojas oficiais.

Ajustar:

- primeiro downbeat;
- início do compasso;
- BPM correto;
- possíveis mudanças de tempo;
- marcadores de transição.

## 10.4 Ganho e volume

Usar auto-gain apenas como referência.

Revisar manualmente:

- clipping;
- diferenças excessivas de volume;
- graves desproporcionais;
- vocais muito baixos;
- edits com masterização inferior;
- MP3 com compressão agressiva.

Não tentar deixar todas as músicas visualmente com a mesma waveform.

O objetivo é consistência auditiva, não uniformidade gráfica.

## 10.5 Tonalidade

Analisar a tonalidade e organizar transições harmônicas.

Usar Camelot Wheel, quando disponível:

- mesma tonalidade;
- uma posição acima;
- uma posição abaixo;
- relativa maior ou menor;
- transições deliberadamente contrastantes nos momentos de ruptura.

Priorizar harmonia nos atos:

- Portal;
- Melodic House;
- Melodic Techno;
- Final emocional.

A compatibilidade harmônica é menos rígida nos flashes nostálgicos e no peak crossover.

# 11. Cue points

Criar até oito hot cues por faixa.

| Cue | Uso |
|---|---|
| A | Primeiro downbeat limpo |
| B | Início do vocal |
| C | Primeiro breakdown |
| D | Build principal |
| E | Drop principal |
| F | Segundo vocal ou segunda frase |
| G | Início da saída |
| H | Ponto de emergência |

### Cores sugeridas

- verde: entrada;
- azul: vocal;
- amarelo: build;
- vermelho: drop;
- roxo: breakdown;
- laranja: saída;
- branco: emergência.

Algumas referências podem estar disponíveis apenas em Radio Edit.

1. localizar trecho instrumental de 8, 16 ou 32 compassos;

3. definir cue de início;
4. criar loop de saída;
5. evitar sobreposição de dois vocais;
6. testar a transição completa;
7. exportar um edit próprio apenas quando necessário.

Manter o arquivo original e o edit em pastas separadas.

# 15. Estratégia de nostalgia

## Regra geral

Na primeira metade:

> Duas faixas de jornada para cada referência nostálgica.

Perto do pico:

> Uma faixa de construção para cada referência reconhecível.

No final:

> Uma faixa de ápice seguida de uma faixa emocional.

## Proporção sugerida

- 70% construção e identidade;
- 20% faixas reconhecidas;
- 10% surpresas, edits, mashups e acapellas.

O reconhecimento perde impacto quando ocorre em todas as transições.

---

# 16. Técnicas de transição

## Transições longas

Usar em:

- progressive;
- melodic house;
- melodic techno;
- trance.

Duração:

- 32 a 64 compassos;
- ocasionalmente mais, quando as faixas permitirem.

## Transições rápidas

Usar em:

- flashes nostálgicos;
- electro;
- peak crossover;
- faixas muito conhecidas.

Duração:

- 8 a 32 compassos.

## Troca por breakdown

Usar quando:

- o BPM muda;
- a tonalidade é incompatível;
- há troca forte de gênero;
- a faixa de entrada possui vocal marcante.

## Echo out

Usar com moderação:

- final de vocal;
- saída de flash nostálgico;
- mudança de capítulo;
- correção de emergência.

## Filtro

Usar para:

- reduzir graves da faixa de saída;
- introduzir groove gradualmente;
- evitar choque de kicks;
- preparar breakdown.

Evitar manter filtro ativo por tempo excessivo.

# 17. Controle de energia

Avaliar cada faixa de 1 a 5.

| Nível | Descrição |
|---|---|
| 1 | Atmosférica |
| 2 | Groove leve |
| 3 | Dançante |
| 4 | Alta energia |
| 5 | Pico |

Curva sugerida:

```text
1 → 2 → 2 → 3 → 3 → 4 → 3 → 4 → 5 → 4 → 5 → 3
```

A queda depois de Under Control é intencional. Ela permite reconstruir o set para o pico do melodic techno.

# 19. Plano de ensaio

## Ensaio 1 — Organização

Objetivo:

- importar arquivos;
- corrigir nomes;
- verificar qualidade;
- analisar BPM e tonalidade;
- separar atos.

## Ensaio 2 — Beatgrid e cues

Objetivo:

- corrigir beatgrids;
- criar hot cues;
- criar loops;
- definir pontos de entrada e saída.

## Ensaio 3 — Transições por blocos

Praticar separadamente:

- Ato 1 para Ato 2;
- Ato 2 para Ato 3;
- Ato 3 para Ato 4;
- Ato 4 para Ato 5;
- Ato 5 para Ato 6;
- Ato 6 para Ato 7.

## Ensaio 4 — Set completo

Objetivo:

- gravar o set completo;
- não interromper por erros pequenos;
- anotar problemas após a gravação.

## Ensaio 5 — Revisão

Ouvir a gravação e avaliar:

- volume;
- excesso de vocais;
- duração das faixas;
- quedas de energia;
- transições apressadas;
- nostalgia excessiva;
- clímax mal posicionados;
- qualidade dos MP3.

## Ensaio 6 — Execução final

Objetivo:

- tocar sem consultar roteiro detalhado;
- usar o setlist como mapa, não como prisão;
- manter uma rota alternativa para cada capítulo.

# 21. Rotas alternativas

## Caso o público responda melhor à nostalgia

Aumentar:

- One;
- Memories;
- Rhythm Is a Dancer;
- Under Control;
- Infinity 2008;
- Summertime Sadness.

Reduzir:

- faixas longas de abertura;
- melodic techno muito abstrato;
- transições excessivamente contemplativas.

## Caso o público responda melhor ao melodic techno

Aumentar:

- Best of Me;
- For a Feeling;
- In The Night;
- Last Night;
- Enjoy the Silence.

Reduzir:

- flashbacks comerciais;
- EDM vocal;
- eurodance.

## Caso o público esteja disperso

Usar:

- vocal reconhecível;
- refrão curto;
- faixa com groove claro;
- transição mais rápida.

Evitar:

- breakdown longo;
- sequência de três faixas introspectivas;
- aumento abrupto de BPM.

# 22. Resultado esperado

O set não deve parecer uma playlist de sucessos.

Ele deve transmitir uma narrativa coerente:

> O público entra por uma atmosfera desconhecida, reconhece fragmentos da própria memória, atravessa momentos de celebração e tensão, alcança um pico físico e retorna a um fechamento emocional.

A nostalgia deve funcionar como gatilho, não como tema exclusivo.

A identidade principal permanece:

> Melodia transcendental, groove brasileiro, clássicos em roupagem moderna e um final emocional memorável.
